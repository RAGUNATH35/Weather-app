# Weather App

A modern Weather Application built using Flutter and Dart that provides real-time weather information for any city.

## Features

- Search weather by city name
- Real-time temperature updates
- Humidity information
- Wind speed details
- Weather condition display
- Clean and responsive UI
- API integration

## Technologies Used

- Flutter
- Dart
- Weather API
- HTTP Package

## Project Structure

```text
lib/
├── main.dart
├── addtional_forecast.dart
├── hourly_forecast.dart
├── weather_screen.dart

```

## Getting Started

### Clone Repository

```bash
git clone https://github.com/RAGUNATH35/weather-app.git
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```

## API Used

This application uses a Weather API to fetch real-time weather data.
